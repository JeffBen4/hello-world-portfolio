# Overview

As a software engineer, my goal with this project is to establish a robust and efficient development environment, master the foundational workflow of version control using Git and GitHub, and ensure seamless deployment pipelines for future software modules.

This repository contains a personalized version of the classic "Hello World" application. Beyond simply outputting text, the software incorporates a customized greeting that reflects my passion for engineering and building impactful digital solutions.

The primary purpose of creating this software is to validate my workspace configuration, refine my project documentation standards using Markdown, and practice clean, structured code delivery ready for collaborative or production environments.

[Software Demo Video](https://youtu.be/EvRcsQqnilE)

# Development Environment

The following tools were utilized to architect and manage this project:
* **Visual Studio Code (VS Code):** Used as the primary Integrated Development Environment (IDE) for code writing, syntax highlighting, and terminal execution.
* **Git:** Employed for local version control, tracking changes, and managing repository states.
* **GitHub:** Utilized as the cloud-based hosting service for remote repository storage and portfolio presentation.

The application was developed using **Python 3**, leveraging its clean syntax and native standard output capabilities to execute direct console commands.
